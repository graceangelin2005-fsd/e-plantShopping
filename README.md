🌱 Paradise Nursery – E-Plant Shopping

Paradise Nursery is a modern online plant shopping web application built using React.js and Redux Toolkit. The application allows users to browse different plants, view plant information, add products to a shopping cart, update quantities, and manage their selected items.

📌 About the Project

The main purpose of this project is to create a simple and user-friendly online nursery where customers can explore and shop for plants digitally.

This project demonstrates the use of React components, state management, Redux Toolkit, event handling, and responsive UI development.

✨ Features

- 🌿 Browse a collection of plants
- 🪴 Display plants with images, names, and prices
- 🔍 View available plant products
- 🛒 Add plants to the shopping cart
- ➕ Increase product quantity
- ➖ Decrease product quantity
- 🗑️ Remove products from the cart
- 💰 Calculate the total cart value
- 📱 User-friendly and responsive interface
- ⚛️ Component-based React architecture
- 🔄 Redux Toolkit for cart state management

⚙️ Installation and Setup

1. Clone the repository

git clone https://github.com/graceangelin2005-fsd/e-plantShopping.git

2. Navigate to the project folder

cd e-plantShopping

3. Install dependencies

npm install

4. Start the development server

npm run dev

The application will then run on the local development server provided by Vite.

🛒 How It Works

1. Users open the Paradise Nursery website.
2. Available plants are displayed on the product page.
3. Users can select plants and add them to the cart.
4. The cart displays the selected products and quantities.
5. Users can increase or decrease quantities.
6. Products can also be removed from the cart.
7. The total price is calculated based on the selected products.
